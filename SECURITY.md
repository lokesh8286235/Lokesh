# Security Policy

## Scope

LinkedIn Optimizer is designed to run locally and analyze user-provided profile and job data. It does not need LinkedIn credentials and does not scrape private data.

## Reporting

Please do not disclose security-sensitive details in a public issue. Contact the repository maintainer through GitHub with a minimal reproduction and impact description.

## Design expectations

Security-sensitive changes should preserve local-first behavior, avoid credential collection, and never introduce automatic publishing or impersonation.
