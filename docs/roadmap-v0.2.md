# v0.2 Roadmap

The v0.1 foundation is evidence-first, deterministic, and local-first. The next layer should improve decision quality rather than add cosmetic features.

## Planned

1. **Bullet-level diagnostics** — identify the weakest experience bullets and explain why.
2. **Evidence extraction** — surface metrics, scope, technologies, ownership verbs, and causal outcomes as structured evidence.
3. **Truth-preserving rewrites** — improve structure while requiring user-supplied facts for missing evidence.
4. **Role-aware recommendations** — prioritize gaps based on target-role requirements instead of generic advice.
5. **Calibration dataset** — expand fixtures and lock expected score ranges before changing scoring weights.
6. **Optional semantic matching** — use embeddings only as a supplemental signal; deterministic lexical matching remains available.
7. **Human review boundary** — no automatic publishing, impersonation, scraping, or claims unsupported by source material.
